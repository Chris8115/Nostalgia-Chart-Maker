# Project Package Format

The recommended sharing format is:

```text
.op3song.zip
```

This is a normal zip file with a project JSON and optional assets.

## Typical Contents

```text
project.op3song.json
audio/<source audio file>
midi/<optional midi file>
jacket/<source jacket image>
README.txt
```

## project.op3song.json

The JSON contains:

- song ID
- title
- artist
- mapper/description text
- genre/category values
- BPM
- offset
- duration
- Normal/Hard/Expert/Real charts

## Sharing Rules

Only share packages when you have rights to share every included asset.

Do not distribute copyrighted songs or jacket art unless you have permission.

For public examples, use original audio/art, permissively licensed assets, or project JSON without bundled media.
